Memory, with proof.

Every memory carries identity, truth state and provenance, so an agent can check it before acting on it. A forged memory fails its signature. A contradicted one is flagged.

Memory Market

Truth Layer

Evidence and contradictions. A contested memory is visible before an agent uses it.

Provenance Ledger

Append-only lineage and hybrid-signed receipts an agent can verify.

Package

The Python client signs each call with your Ed25519 actor key. The private key stays on your machine. The client checks a memory it reads against the content_hash the hub recorded.

cd clients/python
pip install .
attested-memory init
attested-memory write "Supplier terms" "Net 30, EUR"

Source of the package: clients/python (Python >=3.9). Self-host the hub with Docker Compose: README.
